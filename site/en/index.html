Everything a concrete building needs.
No surprise modules.

Analysisspace frame · modal
Automatic space frame (6 DOF/node) with rigid diaphragms, own skyline solver, two stiffness passes (cracked ULS / full SLS), modal analysis, γz and real iterative P-Δ — valid beyond the γz = 1.30 limit.
Design to NBR 6118beams · columns · slabs
Beams with effective flange (automatic T-section), torsion and deep beams; columns in biaxial bending, structural walls and corbels; slabs by grid analysis with full punching shear (interior, edge and corner, with shear studs); stairs, tanks, floor vibration.
Structural masonryNBR 16868 — included
Walls as first-class elements: prism strength per storey, opening groups, wind shear-wall checks with calculated grout and reinforcement, block-by-block elevations (M-20 modulation) and hybrid towers over concrete podiums.
Wind & seismicNBR 6123 · 15421
Wind with digitized drag-coefficient chart, 7.5% accidental torsion and global sway imperfections; full seismic workflow — zones, soil amplification, design spectrum, equivalent lateral forces or response-spectrum (SRSS) — feeding the design combinations.
FoundationsNBR 6122
Footings (isolated, combined, property-line with strap beams), pile caps (1–16 piles), caissons, rafts and retaining walls — editable per column, SPT-based soil-structure interaction, and stepped foundations on sloped terrain with code spacing checks.
Drawings & reportDXF · vector PDF
Executive rebar drawings cut from the real bending diagrams, column elevations, slab plans, foundation details — 1:1 vector PDF with ABNT title block, DXF R12 export, bar schedules, quantities with costs and a complete multi-section calculation report.
AI copilotClaude API or local
A chat that reads your model, runs the analysis and proposes edits you approve one by one. Use the Claude API or a fully local model via Ollama — offline and private.

Is it really free? What’s the catch?+

There isn’t one: 100% free and open source (MIT), a permanent project decision. No license, no account, no hidden telemetry — the code is on GitHub.

Does it run natively on my Mac?+

Yes — Apple Silicon, no virtual machine. It’s the only structural software focused on Brazilian codes that runs on macOS. Windows too, of course.

Which codes does it cover?+

NBR 6118 (concrete), NBR 16868 (structural masonry), NBR 6122 (foundations), NBR 6123 (wind), NBR 15421 (seismic), NBR 8681 (combinations), NBR 6120 (loads) and NBR 14432/15200 (fire). Every check cites its code clause.

Can I trust the results?+

Every code module ships with hand-calculated test anchors (480+ tests) and the clause cited in the source. Cross-validation against established software is ongoing and published in the repository — and the engineer’s own review is always required.
